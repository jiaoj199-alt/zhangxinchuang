# 公开版 v0.3.8.6

版本号：`0.3.8.6` / `30806`。

## 修复重点

本次是 v0.3.8.1 的前台入口补丁：

- 守护页「安心规则」新增 **专注模式** 卡片入口。
- 位置放在「应用门禁」下面，避免用户找不到全机专注功能。
- 卡片文案：`全机专注、应急放行与留言`。
- 点击入口后会显示专注模式说明、当前状态、MCP 工具名，并支持 5 分钟测试、保存默认规则、查看锁定页或结束专注。

## 区分说明

- **应用门禁**：用于锁定某一个 App，例如小红书、抖音。
- **专注模式**：用于全机专注，适合睡觉、学习、暂时离开手机。开启后即使解锁进入桌面，也会回到专注锁定页。

## MCP 工具保持

`get_focus_status`、`start_focus_mode`、`end_focus_mode`、`set_focus_plan`、`reply_focus_request`、`approve_focus_unlock`、`deny_focus_unlock` 保持可用。
