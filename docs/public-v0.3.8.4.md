# 公开版 v0.3.8.6

版本号：`0.3.8.6` / `30806`。

本次是 v0.3.8.2 的日记写入兼容补丁，重点修复“能写正文，但保存时报日记本 id 对不上”的反馈。

## 修复内容

- `write_diary_entry` 的 `book_id` 改为可留空。
- 如果旧窗口、计划任务或模型缓存传入旧 `book_id`，手机端会重新兜底判断。
- 如果当前只有一本日记本，会自动写入这一本。
- 如果当前没有日记本，会自动创建默认「TA 的日记」并写入。
- 如果有多本日记本且无法判断目标，会返回 `choices` 候选项，不会静默写错。
- 新增 `book_name` / `book_title` 兼容字段，方便模型按日记本名称写入。

## 未改动

- 不改变已有日记本 id。
- 不迁移、不清空已有本机日记数据。
- 不改动专注模式、应用门禁、小金库、外卖助手和守护日历逻辑。

## 建议用户临时处理

如果仍在旧窗口遇到保存失败，可以让 AI 先重新读取日记本列表，或直接升级到 v0.3.8.6 后重新写入。
