# 掌心窗公开版 v0.3.8.6

版本号：`0.3.8.6` / `30806`。固定签名保持不变。

## 应用门禁 OPPO/ColorOS 修复

- 应用门禁触发优先级调整为：**全屏锁定页 > 全屏悬浮遮罩 > 回到桌面兜底**。
- 锁定命令写入后，会立即检查当前前台 App；如果目标 App 已经在前台，会立刻触发门禁，不再等待下一次窗口切换。
- 无障碍门禁触发从仅监听窗口切换，扩展为窗口切换、窗口变化、内容变化、滑动事件兜底。
- 全屏锁定页会向门禁状态回报“已显示”，方便判断是否需要继续启用遮罩或 Home 兜底。
- 悬浮遮罩仍保留全屏触摸拦截；如果全屏页和遮罩都未确认显示，最后才执行回到桌面。
- 修复部分 OPPO/ColorOS 设备上“锁了目标 App 但还能继续刷”的问题。

## 建议测试

1. 先打开小红书/抖音并停留在前台。
2. 通过 MCP 或本机测试抽屉锁定该 App 1 分钟。
3. 确认无需退出再进入，也能立刻弹出应用门禁页面或遮罩。
4. 再测试：回桌面后重新打开被锁 App，应继续触发门禁。
