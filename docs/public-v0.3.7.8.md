# 公开版 v0.3.7.9

版本号：`0.3.7.9` / `30709`。

## 更新重点

- 新增公开版「今天吃什么」外卖助手，作为守护功能里的独立页面。
- 外卖助手支持单餐预算、今日外卖预算、口味偏好、常点外卖库、记住这道饭、帮我挑、打开链接、复制备注和点到付款页。
- 外卖助手不会替用户付款；最终支付必须由用户本人确认。
- 外卖计划可提交小金库申请。
- 小金库审批通过后会自动生成一条支出记录，不再需要审批完成后手动补记。
- 自动入账通过 `approval_id` / `source_key` 去重，避免重复审批导致重复入账。

APK 输出名：`Zhangxinchuang-public-v0.3.7.9.apk`。
