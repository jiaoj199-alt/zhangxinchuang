# 掌心窗公开版 v0.3.8.6

## 新增：TA 的日记 · 页边纸条批注

这一版给公开版的「TA 的日记」增加了前端批注能力，定位是“批注/页边纸条”，不是评论区。

- 展开一篇日记后，长按某一段正文，即可留下页边纸条。
- 默认不会在每段正文旁放按钮，页面保持干净；只有被批注过的段落才会显示柔和高亮和纸条数量。
- 批注弹窗会显示被批注原文，可选择「喜欢这里 / 抱抱 / 记住了 / 想回应」等心情标签。
- 保存后，批注以浅粉高亮、细竖线、纸质便签卡的形式出现在对应段落下方。
- 日记备份导入/导出会包含批注数据；删除日记或日记本会同步清理对应批注。

## MCP 工具

新增日记批注相关工具，方便陪伴对象读取用户留下的纸条：

- `add_diary_annotation`：给某篇日记的某段添加页边纸条。
- `list_diary_annotations`：按日记本、日记或未读状态查看纸条。
- `read_diary_entry_with_annotations`：读取日记正文时一并带出批注。
- `mark_diary_annotations_seen`：读取并回应后标记已看。
- `delete_diary_annotation`：删除指定纸条，需确认。
