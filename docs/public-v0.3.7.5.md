# 公开版 v0.3.7.9

## 反馈修复

- 门禁悬浮窗兜底改成全屏触摸拦截层，避免遮罩显示但底下 App 仍可点击。
- 小金库首页与生活摘要里的“待审批”改为“审批列表/待处理”，审批数量不再误算历史记录。
- 审批列表页改为“我的申请”和“陪伴者的申请”两个折叠分组。
- 小金库申请记录新增请求方/处理方角色字段，支持后续双向申请。
- MCP 增加 `save_wallet_request_result`，降低处理结果写回时被平台误拦的概率。

版本号：`0.3.7.9` / `30709`。

本版在公开版中加入“小金库”模块：

- 守护页新增小金库入口。
- 小金库支持本地账本、预算规则、待审批、历史月份侧边栏、统计报告。
- 所有“等待审批/审批详情”的名字均读取设置里的陪伴者名称，不写死固定名字。
- MCP 新增小金库工具：读取当前月、读取月份摘要、添加账单、提交花钱申请、读取待审批、审批申请、确认待确认账单、读取/设置预算规则。
- 默认本地保存账单；公开部署不会读取支付密码、不会接管银行卡、不会默认上传完整账单。
