# 掌心窗公开版 v0.3.9.0

版本号：`0.3.9.0` / `30900`。固定签名保持不变。

## 此刻状态媒体读取修复

- 修复「此刻状态」中媒体权限已开启但仍显示“暂无媒体播放”的问题。
- 新增 MediaSession 主动读取，解决只依赖通知回调导致的漏识别。
- 通知扫描仍保留兜底，兼容更多音乐/视频 App。
- 仅读取媒体标题、歌手、专辑、播放状态和应用名，不读取通知正文。

版本号：`0.3.8.7` / `30807`。固定签名保持不变。

## 回家模式设置生效修复

- 修复回家模式开关、强制抱回、阈值分钟、冷却分钟、返回目标输入后没有即时保存的问题。
- 回家模式配置变化后会清空当前计时与冷却缓存，避免关闭后仍沿用旧计时。
- 回家模式只弹窗时不再强依赖返回目标 APP；未设置返回目标时仍可按阈值弹悬浮横幅。
- 观察 APP 列表为空时使用默认观察包名：抖音、小红书，避免设置页看起来开启但实际没有盯住任何应用。
